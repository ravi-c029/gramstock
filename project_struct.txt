```text

STEP 1: SELECT FILE

STEP 2: ANALYZE DATA

- Numeric and date formats.
- Possible identifier fields.

STEP 3: SUGGEST CATEGORY

- MRP, SellingPrice -> Selling Price.

Treat these as mapping suggestions, not guaranteed mappings.

Allow the user to:
- Change a field mapping.

- Valid rows.
- Invalid rows.
- Warnings.
- Missing required values.
- Invalid date values.
- Invalid numeric values.
- Duplicate identifiers.

Show a final preview.
Let the user confirm the import.

Track the import status and errors.
```

# Bhai, ab sabse important implementation strategy

**Poora prompt paste karne ke baad AI agent ko ek hi baar mein sab kuch generate karne ke liye force mat karna.** Prompt mein phases hain, toh agent ko pehle architecture aur design tokens complete karne, phir core workflow implement karne aur uske baad cloud integration karne do.

Mera recommended order:

| Priority | Build Stage | Result |
|---|---|---|
| 1 | Design system + responsive shell | Premium application foundation |
| 2 | Dataset upload + analysis | Core product functionality |
| 3 | Schema editor | Adaptive configuration |
| 4 | Dynamic inventory table | Functional data management |
| 5 | Dashboard generator | Category-specific experience |
| 6 | Database + authentication | Persistent, isolated business data |
| 7 | Docker + AWS storage | Cloud deployment foundation |
| 8 | Monitoring + SLA/TTR | Academic cloud-computing requirements |
| 9 | Testing + polish | Demo-ready MVP |

**Ek final rule:** UI pehle visually complete ho sakta hai, lekin product tabhi complete maana jayega jab upload se lekar schema confirmation, database persistence aur generated dashboard tak ka poora flow actually work kare.

Is tarah GramStock Cloud sirf khoobsurat inventory dashboard nahi, balki ek genuinely adaptive cloud application banega.
